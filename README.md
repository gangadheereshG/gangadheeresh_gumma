# Ganga Dheeresh — Cinematic Portfolio

A complete responsive React + Vite portfolio inspired by the supplied black-and-white reference screenshot. It uses the portrait and resume supplied in this conversation; no stock portraits are used.

## Run locally

1. Install **Node.js 20.19+** (or Node.js 22.12+).
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open the terminal in that folder and run:

```bash
npm install
npm run dev
```

5. Open the localhost address printed in the terminal (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

The deployable website is generated in `dist/`.

## Included

- Responsive cinematic dark portfolio layout
- Home, About, Projects, Skills, Education and Contact sections
- Portrait asset: `public/dheeresh-portrait.png`
- Resume PDF: `public/Gumma-Ganga-Dheeresh-Resume.pdf`
- Motion effects, hover states, mobile navigation and social links

## Personalize before publishing

Review the contact details and profile links in `src/App.jsx`. Replace project links with individual repository/demo URLs if you want to link directly to each project. The project cards currently link to the GitHub profile because individual repository URLs were not provided.
